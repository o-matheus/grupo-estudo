# Adicionar encontros e melhorar os materiais

## Novo encontro

1. Crie uma pasta `AAAA-MM-DD - Tema` na raiz do repositório.
2. Adicione um README usando o modelo abaixo.
3. Inclua apresentações, guia prático e código quando fizerem parte da atividade. Use links relativos para conectar os materiais.
4. Registre fontes e pré-requisitos. Explique os comandos e os resultados esperados.
5. Acrescente uma linha à tabela de encontros no README principal.
6. Confira os links e execute os exemplos antes de propor a contribuição. Registre limitações ou verificações pendentes.

## Modelo de README do encontro

```markdown
# Tema — encontro de DD/MM/AAAA

## Objetivo

O que o grupo deverá entender ou conseguir fazer ao final.

## Pré-requisitos

Conhecimentos, ferramentas e preparação necessária.

## Materiais

- [Apresentação](apresentacao.html)
- [Atividade prática](atividade.html)
- [Exemplo e instruções](exemplo/README.md)

Inclua somente links para arquivos que existem neste encontro.

## Como acompanhar

Ordem de leitura, execução e respostas esperadas.

## Fontes e próximos passos

Links de estudo e exercícios de continuidade.
```

## Cuidados com contribuições

- Não inclua credenciais, tokens, arquivos `.env` reais ou dados pessoais de participantes. Para configuração, use `.env.example` com valores fictícios.
- Mantenha tentativas individuais em `minha-pratica`; essa pasta não é versionada. Exemplos revisados ficam em `exemplo`.
- Antes de incluir capturas, confira seu conteúdo e remova informações que não fazem parte da atividade.
- Nas alterações, explique o problema resolvido e como o exemplo foi conferido.
